# Xense Energy Systems — Website (Migrated)

---

## 🚀 Active Stack & Architecture

The production marketing website, CEO lead desk, and IoT energy dashboard are now unified in the Next.js App Router codebase:

* **Framework:** Next.js 16 (App Router) + React 19 + TypeScript
* **Styling:** Tailwind CSS + Lucide Icons
* **Database & Auth:** InsForge Cloud PostgreSQL (PostgREST API)
* **Telemetry:** MQTT HiveMQ Broker (esp32-xs-001)
* **Analytics & Performance:** Vercel Speed Insights & Web Analytics

### Key Routes in Unified App:
1. **`/website`** — Full interactive marketing landing page, product ecosystem, interactive battery simulator, and priority lead capture forms.
2. **`/admin`** — CEO Executive Admin Portal with live pipeline KPIs, 1-click WhatsApp/Call/Email links, and CSV export.
3. **`/`** — Core real-time energy IoT operations dashboard.
